# Doto display font

Doto by The Doto Project Authors / Oliver Lalan is bundled unchanged from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/doto).
Upstream filename: `Doto[ROND,wght].ttf`; local filename: `Doto.ttf`.

License: SIL Open Font License 1.1, included in `OFL-Doto.txt`.
Retrieved 24 October 2026. The app loads it locally for display headings
and gain numerals. Small labels continue to use the system UI font.
